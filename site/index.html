Sign and install AltStore, SideStore and LiveContainer from the iPhone itself, with your own Apple ID.

Help

Questions

Get doesn't do anything.

Use Safari on the iPhone, accept the Terms and add the DNS profile first. If one copy won't install, try another.

Sign-in fails inside AltLoad.

Keep Settings › Anisette on Automatic. If it still fails, tap Reset Anisette Data and try again in a few minutes.

"Not enough available App IDs".

Set App Extensions to Keep, Use Main Profile or Remove Extensions before installing.

Does AltLoad see my password?

No. It goes only to Apple, and a remembered one stays in the iPhone's Keychain.
