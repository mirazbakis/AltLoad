AltLoad

On-device sideloader for AltStore, SideStore and LiveContainer. Install it in three steps below.

Version … iOS 27 or later
Download IPA GitHub

No computer

Pairs the iPhone with itself, then signs and installs your store right on it.

Refreshes itself

An AltServer runs on the phone, so AltStore keeps your apps signed.

Your Apple ID only

Your password goes to Apple and nowhere else. No accounts, no tracking.

Setup

Install DNS Profile
  1. Tap Install DNS Profile and tap Allow when Safari asks to download it.
  2. Open Settings and tap Profile Downloaded (or General › VPN & Device Management), then tap Install.
  3. In General › VPN & Device Management › DNS, make sure AltLoad is selected. Keep it on until AltLoad is installed.

Questions

Install doesn't do anything.

Open this page in Safari on your iPhone or iPad, accept the Terms, install the DNS profile, then tap Install and confirm. Once it's on the Home Screen, trust it in Settings › General › VPN & Device Management. If one doesn't work, try another.

Sign-in fails. What now?

Since 12 October 2026 Apple turns down sign-in data from many public anisette servers. Leave Settings › Anisette on Automatic so AltLoad tries the servers that still work, and if it keeps failing, tap Reset Anisette Data and try again a few minutes later.

An app has too many extensions for my free Apple ID.

Before installing, set App Extensions to Keep, Use Main Profile (one App ID for the whole app) or Remove Extensions. A free Apple ID has 10 App IDs a week.

Does AltLoad see my password?

It's sent only to Apple. If you choose Remember password, it stays in this iPhone's Keychain and never syncs. There's no analytics or tracking.

It can't connect to the iPhone.

Check that LocalDevVPN is connected, Developer Mode is on, and this iPhone is paired in Tools › Pair. If it still fails, pair again.
