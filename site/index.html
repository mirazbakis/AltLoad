How it works

Three steps, all on the phone.

  1. Install AltLoad

    Sign it with your own Apple ID from three free apps, or add the DNS profile and tap a signed install.

  2. Pair it with itself

    Tools › Pair shows a code in your Dynamic Island. Type it into Settings › Developer.

  3. Pick a store

    Turn on LocalDevVPN, choose AltStore, SideStore or LiveContainer, sign in, done.

Apple ID Install (No DNS)

Signed by you, on the iPhone, with three free App Store apps. Tick each step as you go; this page keeps your place.

  1. 01

    Pair the iPhone with itself

    rootshell

    This lets AltLoad's installer talk to your iPhone. You only do it once.

    Get rootshell

    In rootshell's settings, switch Location Diary Mode to Session Only so iOS doesn't pause it while you're in Settings. Then enter these two lines, one at a time:

    curl -fsSLO https://github.com/mirazbakis/AltLoad/releases/latest/download/altpair.wasm
    ifconfig en0 | ./altpair.wasm

    rootshell shows a 6-digit PIN. Open Settings › Privacy & Security › Developer Mode and tap the new row at the very bottom, Pair with AltLoad. Enter your passcode, then the PIN. Leave rootshell open.

    What you'll see
    ‹ Privacy & Security
    Developer Mode
    Developer Mode
    Pair with AltLoad›
    rootshell shows this482 017
    If this doesn't work
    • Pair with AltLoad doesn't appear.Check Developer Mode is on and the iPhone is on Wi-Fi, then run the two lines again and reopen Settings.
    • The PIN was rejected.Run ./altpair.wasm again for a new PIN; each one works once.
    • rootshell stopped.Set Location Diary Mode to Session Only and allow Local Network access, then start again.
    • It says wasm: command not found.This copy of rootshell can't run .wasm programs. Update rootshell from the App Store, then run the two lines again.
  2. 02

    Open the tunnel

    LocalDevVPN

    The installer reaches your iPhone through this local tunnel.

    Get LocalDevVPN

    Open LocalDevVPN, tap Connect and allow the VPN configuration if iOS asks. It only links the iPhone to itself; your internet traffic doesn't go through it.

    What you'll see
    LocalDevVPN
    LocalDevVPNLocal tunnel
    Connected
    If this doesn't work
    • LocalDevVPN won't connect.Open it, remove the VPN configuration, add it again and tap Connect.
    • Another VPN is on.Turn it off; iOS runs one VPN at a time.
  3. 03

    Sign and install

    Open Minis

    This signs AltLoad with your Apple ID and installs it, so no shared certificate is involved.

    Get Open Minis

    In Minis's terminal, enter:

    wget -qO- https://mirazbakis.github.io/AltLoad/install.sh | sh

    Type the transfer code rootshell shows, then your Apple ID and password. Stay in Minis until it says Done; iOS pauses it in the background.

    What you'll see
    Transfer code: ______ Apple ID: you@icloud.com Installing AltLoad… 100% Done
    If this doesn't work
    • It can't find the pairing file.Keep rootshell open in the background and type the transfer code it shows.
    • Sign-in fails.Check the Apple ID and password. Two-factor codes go to your other devices. If none arrives, type r to resend it or s to get it by text.
    • It stops partway.Check LocalDevVPN is still connected, then run the line again.
  4. 04

    Trust it

    Settings

    iOS won't open an app from a new developer until you trust it.

    Settings › General › VPN & Device Management › your Apple ID › Trust. AltLoad is on your Home Screen, signed by you.

    What you'll see
    ‹ General
    VPN & Device Management
    Developer App
    Apple Development:you@icloud.comTrust
    If this doesn't work
    • AltLoad closes right away.Trust it first. If it still closes, delete it and run step 3 again.
    • Your Apple ID isn't listed.Step 3 didn't finish. Run it again and stay in Minis until Done.

Pairing and install run on altpair, AltLoad's own open-source tools. Your Apple ID password is typed into altpair on your iPhone and goes to Apple only.

Features

Everything a computer did, on the phone.

Every store

AltStore Classic and Beta, SideStore, SideStore + LiveContainer, stable or nightly. Or any IPA from Files.

Keeps itself signed

An AltServer runs on the iPhone, so AltStore refreshes your apps. AltLoad reminds you the day before anything expires.

App ID friendly

Keep extensions, sign them with the main profile, or strip them. See every App ID and when it frees up in Tools.

Developer tools

JIT for emulators, location simulation, entitlements, certificates, and pairing files for SideStore and StikDebug.

Your Apple ID stays yours

The password goes to Apple and nowhere else. A remembered one lives in this iPhone's Keychain and never syncs. No accounts, no analytics.

Troubleshoot

Questions

Which install should I pick?

Apple ID Install. It takes about 10 minutes and signs AltLoad with your own account, so there is no shared certificate for anyone else to revoke. Direct Install takes about 2 minutes and needs a DNS profile, but it only works while one of its shared certificates is still valid.

Do I have to do this every week?

No. With a free Apple ID, signed apps last 7 days. Once AltLoad is installed, it refreshes itself and the stores it installed, and reminds you the day before anything expires. AltLoad itself is refreshed from inside the app.

Is my Apple ID safe?

Your password goes from your iPhone to Apple only, typed into AltLoad's own open-source installer. Nothing is stored on a server, and AltLoad never sees it; a remembered one stays in your iPhone's Keychain.

Tapping Install does nothing.

That's Direct Install: open this page in Safari, accept the Terms and add the DNS profile first. If a signed install still won't install, its certificate may be revoked. Pick another one, or use Apple ID Install.

"Pair with AltLoad" isn't in Settings.

Developer Mode has to be on, rootshell needs Local Network access, and both must be on Wi-Fi. Run the two rootshell lines again, then reopen Settings › Privacy & Security › Developer Mode.

It installed but won't open.

Trust it in Settings › General › VPN & Device Management. If it still closes right away, that install's certificate was revoked. Delete it and pick another signed install.

Sign-in fails inside AltLoad.

Keep Settings › Anisette on Automatic. If it keeps failing, tap Reset Anisette Data and try again a few minutes later.

"Not enough available App IDs".

A free Apple ID gets 10 a week. Set App Extensions to Keep, Use Main Profile or Remove Extensions before installing, and check Tools › App IDs to see when the next one frees up.
