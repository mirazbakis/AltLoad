Setup

Install the DNS profile first.

Install DNS Profile
  1. Tap Install DNS Profile above and tap Allow when Safari asks to download the configuration profile.
  2. Open Settings and tap Profile Downloaded (or go to Settings → General → VPN & Device Management), then tap Install.
  3. Apply the DNS: in Settings → General → VPN & Device Management, open DNS and make sure AltLoad is selected. Keep it on until setup is complete.

Completion

You're all set.

That's it. Trust AltLoad in Settings → General → VPN & Device Management, open it from your Home Screen, pair in Tools › Pair, and install AltStore, SideStore or LiveContainer straight from your iPhone. No computer needed.

Once AltLoad is installed, the DNS profile is no longer needed. Remove it in Settings → General → VPN & Device Management → AltLoad → Remove Profile, or switch DNS back to Automatic.

Questions

Install doesn't do anything.

Use Safari on your iPhone or iPad, accept the Terms, install the DNS profile, then tap Install and confirm. If one doesn't work, try another.

Sign-in fails in AltLoad.

Leave Settings › Anisette on Automatic so AltLoad tries the servers that still work. If it keeps failing, tap Reset Anisette Data and try again a few minutes later.

"Not enough available App IDs".

Before installing, set App Extensions to Keep, Use Main Profile or Remove Extensions. A free Apple ID has 10 App IDs a week.

Does AltLoad see my password?

It's sent only to Apple. If you choose Remember password, it stays in your iPhone's Keychain and never syncs. There's no analytics or tracking.
