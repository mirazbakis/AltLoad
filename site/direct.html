Direct Install

Version …About 2 minutes

Open altload.org/direct in Safari on the iPhone or iPad you're setting up.

These copies share certificates, so any of them can stop working. For a copy signed by you that nobody else can revoke, use Apple ID Install.

If it doesn't work

Tapping Install does nothing.

Tick the Terms box above, and make sure you're in Safari, not another browser or an in-app browser. If it still does nothing, add the DNS profile first.

"Unable to install AltLoad".

That certificate is revoked or full. Tap Install AltLoad again, or pick another certificate from the list.

It installed but won't open.

Trust it in step 3. If it closes right away, its certificate was revoked: delete it and install from another certificate.

None of them work.

All the shared certificates can be revoked at once. Use Apple ID Install, which signs AltLoad with your own Apple ID.
