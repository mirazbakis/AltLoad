## AltLoad 1.6.2

A fix release for installs that timed out while connecting, and for the Apple ID installer in Open Minis.

### Fixed
- **"Couldn't open a tunnel to this device" during installs.** When an install and the JIT tab connected to the iPhone at the same moment, both could stall. AltLoad now sets up one connection at a time, and gives up on a setup that hangs instead of blocking the next one. The JIT tab also waits for a running install to finish before it lists apps.
- **"Protocol not available (os error 92)" in Open Minis.** The installer used socket options that Open Minis doesn't support when it fetched the pairing file and checked LocalDevVPN. It no longer does. Run the install line again to get the new installer.

### Changed
- **Logs moved to Settings.** Open them from the gear at the top right, under Logs. They now read like a terminal, oldest at the top and scrolled to the newest line.
- The log no longer repeats the pairing port before every device call, only when it changes.

If something still fails, open Settings › Logs, tap Copy and paste it into an issue.
