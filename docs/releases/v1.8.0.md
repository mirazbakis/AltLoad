## AltLoad 1.8.0

Sources, Korean, a name for your certificate, and fixes for installs that timed out while connecting and for the Apple ID install tools.

### New
- **Sources.** Add AltStore and SideStore sources from the Install tab's **…** menu, then browse their apps, read release notes and install them. Apps from a source show **Update** when a newer version is out, in Sources and in Your Apps, and an app's page lists older versions too. Paste an https link or an `altstore://` / `sidestore://` source link; AltStore, SideStore and Husk are one tap away.
- **Korean.** AltLoad and its readme are now in Korean.
- **Certificate name.** Settings › Certificate Name sets the name AltLoad gives the development certificate it requests, which your Apple ID's certificate list shows. Changing it makes AltLoad request a new certificate on the next install or refresh.

### Fixed
- **"Couldn't open a tunnel to this device" during installs.** When an install and the JIT tab connected to the iPhone at the same moment, both could stall. AltLoad now sets up one connection at a time, and gives up on a setup that hangs instead of blocking the next one. The JIT tab also waits for a running install to finish before it lists apps.
- **Pairing tool stuck at "Reading ifconfig from stdin...".** rootshell doesn't always finish sending `if.txt`, so the tool waited forever. It now reads `if.txt` by itself. Download it again with the `curl` line.
- **"Protocol not available (os error 92)" in Open Minis.** The installer used socket options that Open Minis doesn't support when it fetched the pairing file and checked LocalDevVPN. It no longer does. Run the install line again to get the new installer.
- Spanish, Japanese and Portuguese (Brazil) are now listed as the app's languages, so iOS offers them in Settings › AltLoad › Language.

### Changed
- **Logs moved to Settings.** Open them from the gear at the top right, under Logs. They now read like a terminal, oldest at the top and scrolled to the newest line.
- The log no longer repeats the pairing port before every device call, only when it changes.

If something still fails, open Settings › Logs, tap Copy and paste it into an issue.
