## AltLoad 1.5.0

### New
- **altpair.** Install AltLoad with your own Apple ID, on the iPhone, with no computer, no DNS profile and no shared certificate. It uses three free App Store apps: rootshell, Open Minis and LocalDevVPN. I wrote it from scratch; the steps are on the [website](https://mirazbakis.github.io/AltLoad/) and the source is in [altpair](https://github.com/mirazbakis/AltLoad/tree/main/altpair).
- **AltStore without AltServer.** After installing AltStore, AltLoad leaves this iPhone's pairing file where AltStore 2.3.1 and later look for it. Open AltStore › Settings › Set up Remote AltServer once, and it skips pairing; from then on AltStore installs and refreshes apps by itself, with AltLoad closed.
- **JIT that stays.** AltLoad now stays with the app while it asks for JIT memory, which emulators need on newer iPhones, and lets go when the app is done.
- **JIT scripts.** A script decides how AltLoad answers the app. AltLoad's own handles the usual requests, apps can send their own, and you can import .js scripts and pick one per app in Tools › JIT › Scripts.
- **JIT from links and Shortcuts.** Other apps can open themselves with JIT through `altload://enable-jit?bundle-id=…`, and Shortcuts has an Enable JIT action. AltLoad asks before it follows a link.
- **Automatic refresh.** AltLoad refreshes apps that expire within two days by itself, when you open it and in the background. If a certificate is revoked, it signs the affected apps again with a new certificate and provisioning profile. It finds revoked certificates through your Apple ID's developer account, not Apple's OCSP servers, which DNS profiles often block. It needs LocalDevVPN on and the Apple ID's password saved; turn it off in Settings › Automatic Refresh.
- **Several Apple IDs.** Save more than one in Settings and switch in the sign-in form. Each app remembers the Apple ID that signed it, so a refresh uses the same one.
- **UTM, MeloNX and Madeira.** Install them from the store list. Madeira gets this iPhone's pairing file for its built-in JIT; UTM and MeloNX get an **Open with JIT** button right after installing.
- **Install time.** The success screen shows how long the install took.

### Changed
- **Faster installs.** The app unpacks while you sign in instead of after.
- **New website.** A cleaner black and white design, with clearer install steps.

altpair, the new JIT sessions, automatic refresh and AltStore's Remote AltServer setup are new and haven't had wide testing yet. If something doesn't work, please open an issue.
