## AltLoad 1.2.0

A new look, AltStore Beta, and developer tools that used to need a Mac.

### New
- **AltStore Beta.** Pick Release or Beta on the Install tab. Both come from AltStore's official source.
- **Checks the iPhone for AltStore** instead of trusting AltLoad's own records, so a deleted or separately installed AltStore shows up correctly.
- **Entitlements** (Settings › Entitlements): switch on capabilities such as Increased Memory Limit for AltStore's signature. Free-account and paid-account ones are listed separately.
- **JIT** (Tools › JIT): open emulators and other JIT apps with JIT enabled.
- **Location** (Tools › Location): make the iPhone report any place on the map, for every app.
- **Special thanks** in Settings.

### Changed
- Midnight design throughout, including a new app icon. Settings is now made of cards.
- AltServer's background mode is on by default, so AltStore finds AltLoad without it being open.
- Catalyst is no longer offered.

### Fixed
- **Apple ID sign-in.** Apple stopped accepting older anisette data. AltLoad now uses isideload 0.4.6 and `ani.jkcoxson.com` as the default anisette server. If you were on the old default, you're moved over automatically.
- `.ipa` files can be picked again when installing from Files.

### Install
Download `AltLoad.ipa` below and sideload it with any signing tool. Needs iOS 27 or later.
