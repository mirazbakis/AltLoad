## AltLoad 1.2.0

### New
- **Choose what happens to app extensions.** Before installing a store or an IPA, pick **Keep Extensions**, **Keep, Use Main Profile** (the whole app uses one App ID) or **Remove Extensions**, like SideStore. Handy with a free Apple ID's 10 App IDs a week.
- **Pairing code in the Dynamic Island.** While you pair, the six-digit code shows in the Dynamic Island and on the Lock Screen, so you can read it while you're in Settings.
- **Import a pairing file.** Tools › Pair › Import Pairing File adds a pairing file made on a computer and uses it for installs.
- **Runs on iOS 18 and later.** Below iOS 27 the iPhone can't pair with AltLoad itself, so the Pair screen walks you through importing a pairing file instead.
- **App IDs in Tools.** See every App ID on your Apple ID, how many of the weekly limit are used, and when each one frees up. Pull down to refresh.
- **Another anisette server.** Automatic now also tries jkcoxson's macOS server, after the Windows one, whenever it's up.

### Changed
- **Your apps are on the Install tab** under Your Apps, with a pill to refresh each one. Library is gone.
- **Every pairing file is on the Pair page.** Long-press one to use it for installs, share it or delete it.
- **Entitlements moved to Tools.**
- **Pairing File to Apps lists only sideloaded apps,** like SideStore and StikDebug.
- **Liquid Glass buttons** and **icons without tiles** throughout the app.

### Good to know
- The Dynamic Island code comes from a small widget extension inside AltLoad. With a free Apple ID, sideloading AltLoad uses **2 App IDs** instead of 1.
