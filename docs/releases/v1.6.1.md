## AltLoad 1.6.1

A fix release for installs, JIT and device tools that stopped with "Connection refused" or "tunnel connect timed out".

### Fixed
- **"Connection refused" on 10.7.0.1:49152.** AltLoad always connected to port 49152, but iOS doesn't keep its pairing service on a fixed port. It usually gets 49152, but after a restart it can move, and every install then failed. AltLoad now looks up the real port over Bonjour. If that doesn't lead to it, AltLoad checks the iPhone's other ports, which takes a few seconds, and remembers the one it finds.
- **Installs on iOS 27.2.** Since iOS 27.2, the iPhone closes a tunnel's services when a new connection to it identifies itself differently. AltLoad now uses the same identity every time, so installs, refreshes, JIT and AltServer no longer cut each other off.
- **Tunnel packet size.** AltLoad now caps the tunnel's packet size, which could make the connection stall on recent iOS versions.
- **A port that never answers** no longer makes an install hang. AltLoad gives up on it after a few seconds and tries the next one.

The iOS 27.2 and packet-size fixes come from the latest version of idevice by jkcoxson. altpair uses the same update.

AltLoad may ask for Local Network access again so it can find the pairing service. If installing still fails, open Tools › Support › Logs, tap Copy and paste it into an issue.
