## AltLoad 1.3.0

### Fixed
- **SideStore no longer asks you to import a pairing file.** AltLoad now hands the pairing file over the way SideStore reads it, on stable and Nightly. If SideStore has already been opened and still asks, restart your iPhone.
- **SideStore + LiveContainer gets the pairing file too.** It's placed for you at install, so there's nothing to import by hand.

### Changed
- **Far fewer Apple ID sign-ins.** AltLoad keeps Apple's developer token after you sign in and reuses it for installs, refreshes and the account screens, so unstable anisette servers and 2FA prompts get in the way less often. Signing out deletes it.
- **Pure black background** with a small navy glow.
- **Cleaner screens.** Pair, Pairing File to Apps and the install results are simpler, and placing a pairing file is now one button.

### Removed
- **Apple TV pairing.** Pairing files you already saved for an Apple TV stay in the list, but they're never used for installs.
