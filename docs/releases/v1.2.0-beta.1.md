## AltLoad 1.2.0 beta 1

This is a beta. It may have rough edges; the latest stable version is still 1.0.1.

### New
- **Pairing code in the Dynamic Island.** While you pair, the six-digit code shows in the Dynamic Island and on the Lock Screen, so you can read it while you're in Settings.
- **Import a pairing file.** Tools › Pair › Import Pairing File adds a pairing file made on a computer and uses it for installs.
- **Runs on iOS 18 and later.** Below iOS 27 the iPhone can't pair with AltLoad itself, so the Pair screen walks you through importing a pairing file instead. Everything else works the same.

### Changed
- **Liquid Glass buttons** throughout the app.
- **Icons without tiles** in About, Settings, Tools and the tab bar.

### Good to know
- The Dynamic Island code comes from a small widget extension inside AltLoad. With a free Apple ID, sideloading AltLoad now uses **2 App IDs** instead of 1.
