## AltLoad 1.8.1

A fix release for AltLoad crashing when LocalDevVPN is on.

### Fixed
- **AltLoad crashed a few seconds after opening, or during an install, while LocalDevVPN was on.** Setting up the connection to the iPhone ran out of stack space in 1.8.0. It now runs on a thread with a larger stack. If you installed 1.6.1 to work around this, you can update now.
- **Clearer connection errors.** When AltLoad can't connect to the iPhone, the error now lists what to try, in order: turn LocalDevVPN off and on, turn off other VPN or proxy apps, use Wi-Fi instead of mobile data, check Developer Mode, reopen AltLoad, and create a new pairing file. When the iPhone rejects the pairing file, it lists how to make a new one.

If something still fails, open Settings › Logs, tap Copy and paste it into an issue.

### Changed
- **altpair has its own repository.** Its source is now at [mirazbakis/AltPair](https://github.com/mirazbakis/AltPair), and AltLoad includes it as a submodule. The tools and the install line are unchanged, and their downloads stay on AltLoad's releases. Its readme has a new troubleshooting section with fixes to try in order.
