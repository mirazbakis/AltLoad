## AltLoad 1.0.0

AltLoad starts over as **com.mirazbakis.altload**, with SideStore and LiveContainer alongside AltStore, a sign-in that works again, and a darker design.

> This is a new app with a new bundle ID. Install it next to (or instead of) the old AltLoad, then pair once more in **Tools › Pair**. Settings and pairing files from the old app don't carry over.

### New
- **SideStore** and **SideStore + LiveContainer**, each as a stable or **nightly** build. Pick one from the store menu on the Install tab.
- **When SideStore's repository is down**, AltLoad tries a mirror, GitHub releases, a known-good build and its own saved copy. If none answer, pick an IPA from Files.
- **Sign in from Settings.** Settings › Apple ID › Sign In checks your Apple ID, including two-factor, without installing anything.
- **About** tab with special thanks and legal links. Settings now opens from the gear at the top right of every tab.

### Fixed
- **Apple ID sign-in.** Since 12 October 2026 Apple refuses sign-in data from many anisette servers. AltLoad now picks a server that's working, moves on to the next one when Apple refuses it, and keeps its anisette data in files instead of the Keychain (which some signing tools break). Use **Reset Anisette Data** in Settings if sign-in keeps failing.
- Installs sign in to Apple first, so a sign-in problem shows up straight away.

### Changed
- Darker midnight design with a navy spotlight, solid cards and bigger buttons.
- New icon: midnight, dark green and white.

### Install
Download `AltLoad.ipa` below and sideload it with any signing tool. Needs iOS 27 or later.
