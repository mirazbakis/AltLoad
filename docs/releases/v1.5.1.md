## AltLoad 1.5.1

A fix release for altpair. The AltLoad app itself is unchanged apart from the version number.

### Fixed
- **altpair two-factor sign-in.** If Apple couldn't send the code to your devices, altpair kept asking for a code that Apple would never accept, and the only way out was to stop. Now it asks where to get a new code. At the code question you can also type `r` to resend the code, `s` to get it by text message (`s1`, `s2`… to pick a number), or `d` to send it to your devices.
- **altpair sign-in messages.** When Apple turns down a sign-in, altpair now points to its own `--anisette <url>` option instead of a Settings screen that only exists in the app.
- **altpair anisette servers.** A server given with `--anisette` and a trailing slash or capital letters is no longer tried twice.

### Changed
- **Troubleshooting for `wasm: command not found`.** The website and altpair's README now explain this rootshell error: that copy of rootshell can't run `.wasm` programs, so update it from the App Store. The pairing tool also needs rootshell 1.0.16-177 or later.

I haven't tested the new two-factor options on a real iPhone yet. If something doesn't work, please open an issue.
