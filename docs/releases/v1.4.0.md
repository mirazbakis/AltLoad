## AltLoad 1.4.0

### New
- **Husk.** Install Husk from the store list, with this iPhone's pairing file already inside it for its built-in JIT.
- **French, German, Italian, Chinese and Russian.** AltLoad follows your iPhone's language.
- **Update notices.** AltLoad tells you when a newer version is out.

### Fixed
- **Pairing files for SideStore and SideStore + LiveContainer.** They now include this iPhone's UDID and go everywhere SideStore looks, along with the settings newer builds need.
- Fixed potential issues with Apple IDs
